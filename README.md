# Minishell

Minishell is a **small Unix shell** developed as part of the **42Prague curriculum**.
The goal of this project is to **recreate basic shell behavior** and gain a deep understanding of **processes, pipes, signals, and system calls** in C.

## 🧩 Features

* Execute simple commands with arguments
* Handle **pipes (`|`)** and **redirections (`<`, `>`, `>>`)**
* Manage **environment variables** (`$PATH`, `$USER`, etc.)
* Support for **built-in commands** (`cd`, `echo`, `pwd`, `export`, `unset`, `exit`)
* Handle **signals** (Ctrl+C, Ctrl+D, Ctrl+) properly
* Basic **error handling** and memory management

## 🛠️ Technologies

* **C**
* **Unix system calls** (fork, execve, pipe, dup2, signal, etc.)
* **Makefile** for compilation
* **Git** for version control

## 👥 Collaboration

Developed in a **team of two** as part of the 42Prague learning program. The project focuses heavily on **teamwork**, **code review**, and **problem-solving**.

## 🚀 Goal

To gain hands-on experience with **low-level programming**, **process control**, and the **inner workings of a Unix shell**.
